## 2. トーンの原則

- 主語は三人称（「参加者は」「森山は」）。会社の声は §10 のみ「PROD」
- PRODIA と同じく、見出しは短く言い切る。英字のeyebrow（`ABOUT` `RESULTS` 等）＋太い和文見出し＋短い本文の3段構成
- 番号付きカード（01／02／03）、ステップ図、数字の大きな表示で「読まなくても伝わる」ページにする
- 煽り・二人称の呼びかけ（「殻を破る準備は〜？」等）は使わない
- 成果を誇張しない。事例には「すべての企画が目標どおりに終わるわけではない」旨を残す
- 会社が主催していると誤読されない書き方にする（安全面の責任所在に関わるため）

## 4. セクション別原稿（たたき台）

### 1. FV
- 背景: 全面写真＋左下に濃紺のグラデーション（PRODIAのヒーローと同じ作り）
- eyebrow: `CEBU STUDY TOUR`
- 見出し: **知らない環境で、**／**自分で決めて**／**<span>動く8日間。</span>**（最後の行だけ明るい青。PRODIAの「なりたい自分を、<span>現実へ。</span>」と同じ扱い）
- リード:
  > セブ島スタディツアーは、PROD社員の森山裕太が代表を務め、2023年から続けている学生向けの海外研修プログラムです。
  > フィリピン・セブ島を舞台に、参加者が自ら企画を立て、現地で実践し、仲間と振り返る。観光でも語学留学でもない、経験から学ぶ8日間をつくっています。
- 写真: 海の上で仲間と笑い合う参加者（`home-definition-fun.jpg`）

### 2. 実績
- 見出し: **10回の開催、170名以上の参加者。**
- 数字4点:
  - 累計参加者 **170名以上**
  - 開催回数 **10回**
  - 海外渡航が初めての参加者 **約80%**
  - 一人で参加した人 **約70%**
- 参加地域: 福岡を中心に、長崎・熊本・関西・関東・北海道から参加しています。
- 補足文: 参加者の多くは、初めての海外に一人で飛び込んだ学生です。
- 注記: ※2026年9月時点

### 3. 背景・目的
- 見出し: **きっかけがあれば、人は動き出せる。**
- 本文:
  > 「やってみたい気持ちはあるけれど、何をしたいのか分からない」「始める前から、自分には難しいと思ってしまう」。
  > そんな学生に必要なのは、正解を教わることではなく、自分で決めて動いてみる経験だと考えています。
  > 言葉も文化も違い、思いどおりにいかない環境だからこそ、仲間に相談し、方法を変え、もう一度試す。その繰り返しから、自分なりの動き方が見えてきます。
- ミッション: **未知を超える** ― 知らない環境へ一歩踏み出し、自分なりの答えをつくる。

### 4. プログラムの特徴
- 見出し: **遊ぶだけで終わらない、経験から学ぶ設計。**
- 3カード:
  1. **考える** ― 自分がセブで試したいことを、自分なりに企画する。
  2. **試す** ― 正解のない街へ出て、考えたことを実際の行動にする。
  3. **振り返る** ― 毎晩、仲間や運営との対話を通して、経験を次の一歩へつなげる。

### 5. 参加前から帰国後までの流れ
- 見出し: **8日間の前後まで、一つの学びとして設計しています。**
- タイムライン（各1行）:
  | 時期 | 内容 |
  |---|---|
  | 出発前 | 事前研修（4時間）― 顔合わせと、セブで試したいことの整理 |
  | Day1〜2 | セブの海と街に触れ、仲間になる |
  | Day3〜5 | 個人企画 ― 自分で決めたことを、セブの街で試す |
  | Day6 | 常夏研修 ― 街をフィールドにした没入型の体験 |
  | Day7〜8 | グループ企画 ― 仲間と一つの企画を形にする |
  | 帰国後 | 帰国報告会 ― 8日間の経験を、自分の言葉で発表する |

### 6. 実践事例
- 見出し: **初日は2人。3日目には100人。**
- 企画名: 「フィリピン人100人に夢を聞く」（西南学院大学 3年）
- 図: 2人 → 60人 → 100人（個人企画1日目・2日目・3日目）
- 本文:
  > セブの街で100人に声をかけ、それぞれの夢を聞く。初日に話を聞けたのは2人でした。
  > 声のかけ方や場所を変えながら試し、2日目には60人、3日目には100人へのインタビューを終えました。
  > 「途中で方法を変えながら続けられたことが、自分にとって大きな経験になりました」
- 注記: すべての企画が目標どおりに終わるわけではありません。結果だけでなく、途中で何を考え、どう動きを変えたかを振り返ります。

## 5. デザイン・HTML実装仕様（PRODIA準拠）

PRODIAページの実装を解析した結果（2026-10-12）に揃える。

| 項目 | 仕様 |
|---|---|
| ページ形態 | WordPressの固定ページに、ページ全体のHTMLを1つ挿入（PRODIAと同じ）。独自のヘッダー・フッターを持つ |
| ヘッダー | 左にPRODロゴ、右にページ内リンク（概要／実績／プログラム／事例／歩み／代表）。**エントリーボタンは置かない**。代わりに「PRODトップへ」 |
| フッター | PRODの会社情報（PRODIAと同じ内容）＋セブ島スタディツアー公式サイトへのリンク |
| フォント | 見出し: Zen Kaku Gothic New（700/900）、英字ラベル・数字: Montserrat（700/800）。Google Fontsから読み込み（PRODIAと同じ） |
| 色 | PRODIAと同じ。濃紺 `#16294e`、ブルー `#2f63e0`、明るい青 `#9dc0ff`、本文 `#444f63`、薄い背景 `#eef2f8`。セブらしさは写真で出し、色は増やさない |
| 背景のリズム | 白／薄い青（`#eef2f8`）／濃紺グラデーションを交互に。濃紺は 実践事例・PRODより の2か所（FVは写真）。濃紺が隣り合わないようにする |
| 角丸・影 | カードは角丸12〜14px、影は `rgba(22,41,78,.06)` 程度の薄いもの |
| 動き | スクロールでふわっと出る（PRODIAの `data-reveal` と同じ方式。JSなしでも全文が読める状態を初期値にする） |
| 見出しレベル | 独立ページなので FV が `h1`、各セクションは `h2` |
| CSS | クラスに `cst-` 接頭辞。WordPressテーマのCSSと衝突させない |
| 画像 | WordPressのメディアにアップロードしたURLを参照する（推奨）。PRODIAのようにbase64で埋め込む場合は、1枚あたり長辺1600px・JPEG品質75程度に圧縮する |
| レスポンシブ | 360px〜。左右16px余白、横スクロールは年表のみ |
| アクセシビリティ | 全画像にalt（site-2027のaltを流用）、コントラストAA |
